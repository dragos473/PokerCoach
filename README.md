# PokerCoach

Personal, fully local poker learning app (React + TypeScript + Vite). No backend, no accounts.

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # engine test suite
npm run build      # production build in dist/
```

See `CLAUDE.md` for architecture, data schemas and the phase checklist. The full README (adding lessons, ranges and quiz content) comes in Phase 7.
